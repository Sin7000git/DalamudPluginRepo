Custom [FFXIVQuickLauncher](https://github.com/goatcorp/FFXIVQuickLauncher) / Dalamud plugin repository.

## Installation

First open the Dalamud Settings menu in the game, accessible through typing `/xlsettings` in the chat or through the button at the bottom of the Plugin Installer.

Then follow these steps:

1. Click the **Experimental** tab.
2. Paste the following into the empty box at the bottom of the **Custom Plugin Repositories** section
  ```
   https://raw.githubusercontent.com/Sin7000git/DalamudPluginRepo/main/pluginmaster.json
  ```
3. Click the **+** button next to it.
4. Click save.

Now these plugins will appear inside the Plugin Installer, accessible through typing `/xlplugins` in the chat.
